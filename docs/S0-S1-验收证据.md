# S0/S1 验收证据（以实际结果为准）

## 证据分类
- **代码证据**：pytest、lint、mypy、迁移测试，以及 PostgreSQL Compose 运行记录。CI 结果必须附准确 SHA。
- **用户确认的历史现场证据**：2026-10-19 Windows 上的远程 Qwen3:14b 调用、多轮对话、重启恢复、SSE 计时、停止生成状态，以及用户报告的可选 E2E 全部通过。此前没有机器可验证的运行 ID，不能假装它们已被 CI 复现。
- **可重复的真实模型验收**：运行 `RUN_LIVE_MODEL_TEST=1 python -m pytest tests/test_live_optional.py -q -m live`。只检查调用成功还不够，必须检查特定上下文问答的内容。
- **禁止伪造**：不能用模拟模型或字符串 smoke 结果充当真实推理基准；没有官方 token 字段时，明确记录 unavailable，不要把字符数当 token。

## S1 关闭规则
核心对话功能已经有用户现场验证。严格 S0/S1 全门禁只有在 PostgreSQL、迁移、CI 以及带 SHA 的真实模型报告全部入证后才允许标记 fully closed。
