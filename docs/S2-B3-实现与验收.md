# S2-B3 — 会话级持久化任务

目标：沿用唯一 Agent 对话入口，使 create_task 与 list_tasks 对同一个 Conversation 持久化，不新增 Agent 路由。

实现：conversation_tasks 表和 Alembic 0002 迁移；ConversationTaskStore 在独立数据库事务中执行任务创建与列表查询；正式 AgentLoop 注入存储适配器，离线 S2-A 测试继续使用运行内列表。

验收：同一会话跨消息读回，服务重启读回，不同会话隔离、不同用户越权 404、重复 client_request_id 拦截、SQLite/PostgreSQL 迁移及回归。真实 Qwen 网页人工测试待用户执行。

限制：每会话任务上限 20；并发限额不是严格串行化；工具副作用提交可能早于最终模型回复，回复失败后须以查询结果为准；尚无修改/删除、工具事件持久化与强恢复。本阶段不宣称生产级 exactly-once 副作用。
