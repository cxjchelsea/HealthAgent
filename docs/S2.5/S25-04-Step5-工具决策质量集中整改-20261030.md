- A/B 只隔离 Tool Calling 的决策指令变量。它不是语义 Top-K、语义独立筛选器，也不承诺性能提升。
- 不改变 `dynamic` 默认值；`semantic_guided` 为显式 opt-in；仍保持 create_task/save_memory 默认隐藏且保留 Host 最终权限检验。
