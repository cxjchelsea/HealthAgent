## Scope of this increment
1. `agent/route_shadow_host.py`: pure, side-effect-free preview of all eight semantic routes. Uses a caller-supplied `ShadowHostFacts` snapshot. Outcomes: `deny`, `needs_evidence`, `safe_non_effect`, `potentially_admissible`. The last is **not** execution authorization.
2. `tests/test_s25_02_m2_shadow_host_matrix.py`: tests for absent plan, first-step replay, completed-plan replay, saved-plan isolation, plan revision source, pending slot field conflict, write source, and non-effect routes.
3. `evals/s25_02_m2_shadow_live.py`: opt-in standalone local-Qwen matrix of 14 semantic route situations. Does **not** invoke Conversation API, Tool Registry, AgentLoop, or DB. Emits case IDs, semantic route results, elapsed time and review counts; does not record user messages or credentials.

## Important constraints and remaining gates
- Existing API Shadow remains default disabled. It executes only after the legacy turn commits; it cannot prevent the legacy chain from performing its actions.
- `ShadowHostFacts` are trusted only **when supplied from a verified Host fixture or real read-only state**. Current live semantic matrix does not validate these facts and does not exercise actual Host admission. Never use model-generated facts as authority.
- M1 fields `goal_change`, source spans and negative constraints have partial contract enforcement; the complete M1 schema, authoritative bindings and versioned Host admission are not implemented.
- Existing `compare_to_legacy` is evidence-limited and abstains when the Host does not expose a unique route. This live semantic matrix is not a full old-vs-new side-effect equivalence test.
- Full M2 exit requires (a) full strict V2 cross-field contract, (b) shadow vs actual legacy route captured per real case with exact IDs, (c) true read-only Host facts for all paths, (d) call-count and p50/p95 latency, and (e) complete real-Qwen runs and source-bound persistence checks.
