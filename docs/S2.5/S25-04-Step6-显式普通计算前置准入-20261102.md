# S25-04 Step 6 — 显式普通计算的受限前置准入

本切片不把 Qwen Shadow 分类作为执行授权，也不允许 M5 错误 CREATE 被拒绝后回退 AgentLoop。

## 客户端请求合同
原有 POST /conversations/{cid}/agent/messages 增加可选字段 selected_ordinary_operation，目前仅支持 calculate。只有如下严格格式才可触发前置仲裁跳过：
```json
{"content":"请计算 (19+23)*4","client_request_id":"unique-identifier-001","selected_ordinary_operation":"calculate"}
```
Host 只接受本轮与严格计算表达式匹配的文本，不接受任何自然语言附加操作或多种意图；如有 pre-turn saved plan、pending action 或澄清状态则绝不跳过 M5。未传字段的自由文本入口**完全保持旧行为**。

## 权限不变式
- 跳过范围仅为无保存计划时的 M5 CREATE **提案**，不是 Host 工具执行授权。
- 原 S25-01 Understanding、execution policy、AgentLoop Tool Schema、工具权限、写同意、Turn、并发和重放校验仍适用。
- 明确计划、混合、指代、扩展表达式、未知 selected_ordinary_operation 不符合 Host 条件；不允许后置 M5 refusal 回退。
- 不使用 Shadow 模型的 label、quote 或置信度作为分流依据。
- 新路径为 opt-in 极窄原型，不能宣称自由文本普通待办/记忆/MCP 问题已修复。
