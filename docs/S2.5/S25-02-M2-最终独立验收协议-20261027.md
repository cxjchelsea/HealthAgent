# S25-02 M2 — 最终独立验收协议（冻结版，2026-10-27）

## 目的与范围
本文件在调整语义分类前冻结，不含实际考试题目。M2 仅作影子诊断，不接管 apps/api/main.py，M3 禁止生产切换。现有 u01–u24（含 u23）及先前 24 条均属已知开发/回归题，不得再用于申报独立泛化通过。

## 语义标签与判分
继续使用现有对象 none/task/plan/plan_step/pending_slot/tool 与各对象合法操作、ROUTE_BY_CORE，不增加隐含 Host 关键词纠错。
- none/clarify：当前请求的首要动作是让助手向用户提出澄清问题，而不是立刻执行所讨论的对象操作。
- plan_step/revise：用户当前请求实际改变某个保存步骤的内容；若修改意图已经成立但缺引用，仍为 revise，Host 待补证/拒绝。
- plan/execute_first：只执行存档计划的首个阶段，不编辑内容。
- tool/invoke：独立工具操作，包括存在待补会话时的新请求。
对象、操作必须同时匹配；失败时即使被 Host 安全阻断仍视为语义失败。需分别核验来源、可信引用、路由一致性、效果与安全预览。未知工具效果不推断。计划创建正向样本必须证明两段非重叠原文来源及可信写入/Schema 后仅 potentially_admissible，不授权执行；对应负向样本必须被阻断。

## 测试独立性
独立测试集由未参与 Prompt 设计、未查看 u23 失败细节及历史题面的人或独立隔离评测方依据上述标签契约编写并审核。开发者在待测 SHA 冻结前不得访问其题面、答案或例题。建议至少 60 条（中英双语、否定、指代、省略、计划/步骤、澄清、Pending/独立工具、工具效果、计划创建正负）。
评测方冻结题面、标签、可信 facts、关键标记、评分程序的哈希；记录编写者与冻结时间。不宣称模型自行生成的公开开发题是第三方盲测。
冻结候选的精确代码 SHA、模型名称/版本、Prompt SHA、参数后，仅对独立集执行两轮；不得在看过错误后改同一卷再算一次验收。

## 门禁
每轮正确率 >=95%；所有预先标记的关键样本两轮均正确；完整唯一 ID、不得缺失/重复；来源与 Host 安全负例零错误授权，host_authorization 恒 false；计划创建正负闭环；输出单独的分类/处置/门禁表，完整原始证据仅在有权限的本地验收目录保存。
任何一项失败即 M2 HOLD。通过时可形成 M2 影子诊断 ACCEPTED 的评审申请，但正式切换仍须另行授权 M3。旧封存题任何分数不能替代独立验收。
