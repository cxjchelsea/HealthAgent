## Integrated implementation

1. Migrated original S25-03 modules services/task_state.py and services/evidence_store.py without rewriting their unit-level contracts.
2. Migrated existing six S25-03 test files and its original design document as historical source.
3. Added original S25-03 ORM entities AgentTaskState, AgentStateTransition and AgentAttempt to the current services/db.py without overwriting M4.
4. Rebases historical S25-03 migration chain to 0011_s25_evidence -> 0012_s25_task_state -> 0013_s25_transitions -> 0014_s25_attempt_link, starting after main 0010_plan_recovery_audit. Updated SQLite migration test and PostgreSQL CI migration assertion.
5. Added services/s25_03_projection.py: only a verified M4 checkpointed dispatch, with matching step/tool/arguments/positive receipt, produces a successful AgentAttempt and causal step transition in the SAME finalization transaction. No extra tool dispatch or inferred authorization.
6. Uncheckpointed dispatched effects map to task status blocked. Other failed requests with a saved plan map to interrupted, retaining step states.
7. Added owner-scoped read-only APIs:
   - GET /conversations/{cid}/agent/task-state
   - GET /conversations/{cid}/agent/task-history
   - GET /conversations/{cid}/turns/{turn_id}/evidence
8. Added integration tests for positive binding, unknown dispatch blockage, mismatched arguments/receipt rejection and fake success trace rejection.

- Read-only task projections do not replace source ConversationPlan and M4 Dispatch/Claim journal. Model outputs and unverified traces cannot become verified execution facts.
- The new branch still requires Step 4 integration review, PostgreSQL migration compatibility, crash/recovery verification and later real-model Step 5 acceptance. CI green alone is not final business acceptance.
