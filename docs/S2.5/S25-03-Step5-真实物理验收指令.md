# S25-03 Step 5 — 真实 Qwen3 + SQLite 物理验收

本文件是给 Windows PowerShell、本地 Ollama Qwen3:14b 的独立物理测试指令。当前仅表示可执行验收流程；**真实运行通过与否必须以生成的本地报告和 DB 证据为准**。所有命令在 D:\HealthAgent 执行。

## Terminal A — API 进程

先 Ctrl+C 停止已有 8012 服务，再执行：

```powershell
Set-Location D:\HealthAgent
.\.venv\Scripts\Activate.ps1
git fetch origin
git switch integration/s25-03-mainline-convergence
git pull --ff-only origin integration/s25-03-mainline-convergence
git status --short
git rev-parse HEAD

$dir = "artifacts\s25-03-step5-real"
New-Item -ItemType Directory -Path $dir -Force | Out-Null
if (Test-Path "$dir\healthagent.db") { throw "不能复用旧物理数据库；请用全新目录" }

foreach ($name in @("ROUTING_PROFILE","ROUTE_ADMISSION_MODE","UNDERSTANDING_STRATEGY",
    "M5_UNIFIED_ROUTE_ENABLED","M5_FIRST_ROUTE_ENABLED","ROUTE_SHADOW_ENABLED")) {
    [Environment]::SetEnvironmentVariable($name, $null, "Process")
}
$env:DATABASE_URL = "sqlite:///./artifacts/s25-03-step5-real/healthagent.db"
$env:MODEL_PROVIDER = "ollama_proxy"
$env:MODEL_BASE_URL = "http://127.0.0.1:11434/api"
$env:MODEL_NAME = "qwen3:14b"
$env:UNDERSTANDING_LIGHT_MODEL = "qwen3:14b"
$env:UNDERSTANDING_STRONG_MODEL = "qwen3:14b"
$env:MODEL_TIMEOUT_SECONDS = "180"
$env:MODEL_MAX_OUTPUT_TOKENS = "2048"
$env:ALLOW_DEMO_IDENTITY = "true"
$env:USER_TOKENS = ""

python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8012
```

注意：检查 .env 是否包含旧路由强制值，若有需注释。不要启用 Shadow，它与 S25-03 执行证据无关，并且会额外调用模型。

## Terminal B — 真实 HTTP 与只读物理审计

```powershell
Set-Location D:\HealthAgent
.\.venv\Scripts\Activate.ps1
$dir = "artifacts\s25-03-step5-real"
New-Item -ItemType Directory -Path $dir -Force | Out-Null

git rev-parse HEAD | Out-File "$dir\git-head.txt" -Encoding utf8
git status --short | Out-File "$dir\git-status.txt" -Encoding utf8
$profile = Invoke-RestMethod "http://127.0.0.1:8012/model"
$profile | ConvertTo-Json -Depth 12 | Out-File "$dir\runtime-profile.json" -Encoding utf8
if ($profile.provider -ne "ollama_proxy" -or
    $profile.routing_profile -ne "unified" -or
    $profile.routing_profile_source -ne "auto_real_provider_default" -or
    $profile.m5_unified_route_enabled -ne $true -or
    $profile.route_admission_mode -ne "guarded") {
    throw "当前 API 不是预期的 Qwen3 M5 默认主链；不要继续"
}

foreach ($name in @("ROUTING_PROFILE","ROUTE_ADMISSION_MODE",
  "UNDERSTANDING_STRATEGY","M5_UNIFIED_ROUTE_ENABLED","M5_FIRST_ROUTE_ENABLED")) {
    [Environment]::SetEnvironmentVariable($name, $null, "Process")
}
$env:RUN_S25_02_M5_UNIFIED_LIVE = "1"

python -m evals.s25_02_m5_unified_live `
    --endpoint http://127.0.0.1:8012 `
    --require-default-profile `
    --output "$dir\live.json" `
    --timeout 240
if ($LASTEXITCODE -ne 0) { throw "真实 Qwen3 主链 11 场景未通过；保留证据" }

python -m evals.s25_02_m5_unified_physical `
    --db "$dir\healthagent.db" `
    --live "$dir\live.json" `
    --output "$dir\m5-physical.json"
if ($LASTEXITCODE -ne 0) { throw "旧 M5 物理边界回归未通过" }

python -m evals.s25_03_step5_physical `
    --db "$dir\healthagent.db" `
    --live "$dir\live.json" `
    --output "$dir\s25-03-physical.json"
if ($LASTEXITCODE -ne 0) { throw "S25-03 证据物理验收未通过" }

Get-Content "$dir\s25-03-physical.json" -Raw | ConvertFrom-Json |
    Select-Object verdict,summary
```
