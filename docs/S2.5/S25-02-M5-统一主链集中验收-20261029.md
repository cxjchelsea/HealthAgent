# S25-02 M5 Unified — Real Qwen3 集中验收（候选门禁）

> 本文件只定义执行命令及合格判据。GitHub CI 的 Mock/契约 PASS 不能替代真实 Qwen3 + SQLite 数据证据。M5 未合并/未启用为默认路径。

## 0. 前置条件

- Windows PowerShell，项目目录 `D:\HealthAgent`；两个终端在**同一个仓库目录**。
- 最新 `feat/s25-02-m5-unified-mainline-20261029`，Python 虚拟环境与依赖已安装。
- 本地已运行 Ollama，模型 `qwen3:14b` 可用；请求不会发送外部副作用，仅用新的隔离 SQLite 数据库。
- 不要在正在提供真实工作会话的服务、共享数据库或生产环境运行。
- 目标为 11 条实时 HTTP 场景的 PASS，随后独立只读 SQLite 检验全部 PASS；如 FAIL，不要自行改报告或强行合并。

## 2. 终端 B：探针 + HTTP 验收

```powershell
Set-Location D:\HealthAgent
.\.venv\Scripts\Activate.ps1
$env:RUN_S25_02_M5_UNIFIED_LIVE = "1"
$env:UNDERSTANDING_STRATEGY = "structured"
$env:ROUTE_ADMISSION_MODE = "guarded"
$env:M5_UNIFIED_ROUTE_ENABLED = "true"
$dir = "artifacts\m5-unified-acceptance"
$model = Invoke-RestMethod "http://127.0.0.1:8012/model"
$model | ConvertTo-Json -Depth 5
if ($model.provider -ne "ollama_proxy" -or
    $model.route_admission_mode -ne "guarded" -or
    $model.m5_unified_route_enabled -ne $true) {
    throw "API is not the expected real unified guarded instance"
}

python -m evals.s25_02_m5_unified_live `
    --endpoint http://127.0.0.1:8012 `
    --output "$dir\live.json" --timeout 240
$liveExit = $LASTEXITCODE
$report = Get-Content "$dir\live.json" -Raw -Encoding UTF8 | ConvertFrom-Json
$report.records | Select-Object case,http,verdict,model_http_attempts |
    Format-Table -AutoSize
$report.summary
if ($liveExit -ne 0 -or $report.verdict -ne "PASS") {
    throw "M5 live acceptance failed: inspect live.json before any physical checks"
}
```

验收顺序：CREATE_A → FIRST → RESUME → REPLAY → CREATE_B → REVISE → CREATE_C → CANCEL → ORDINARY → PENDING → PENDING_ANSWER。失败的会话组会阻断其后续依赖场景，但其他独立会话继续运行。

**要求：11 PASS / 0 FAIL / 0 BLOCKED**，且每个非 REPLAY / PENDING_ANSWER 的路由必须有 `primary == 1`、`plan_intent == 0`。这不是所有模型 HTTP 请求次数等于 1 的声明。

## 3. 独立 SQLite 物理读回

仅当 live.json PASS 后运行。此工具不修改数据库。

```powershell
$dir = "artifacts\m5-unified-acceptance"
python -m evals.s25_02_m5_unified_physical `
    --database "$dir\healthagent.db" `
    --live-report "$dir\live.json" `
    --output "$dir\physical.json"
$physicalExit = $LASTEXITCODE
$physical = Get-Content "$dir\physical.json" -Raw -Encoding UTF8 | ConvertFrom-Json
$physical.checks | Format-Table name,result -AutoSize
$physical.summary
if ($physicalExit -ne 0 -or $physical.summary.FAIL -gt 0) {
    throw "M5 physical readback failed"
}
```

核验真实 Turn 和 Assistant Message 持久化、REPLAY 无额外 Turn、生命周期和修订的真实计划状态、取消后的计划不存在、普通/Pending 不误存计划、精确 Dispatch Turn/Step/参数/Checkpoint 关联、无活跃 Claim 和 SQLite 完整性。

## 4. 限制与合并门禁

- 该验收程序无法在 GitHub 的 Fake/Mock CI 中声称执行了本地 Qwen3。
- 目前物理检查仅覆盖相同隔离 SQLite 数据库，不意味着 PostgreSQL 真实模型物理 E2E 或非幂等外部操作 exactly-once。
- 建议上传 `live.json`、`physical.json` 中**脱敏后的结果**供独立审查；原始文件可能包含完整会话内容，不可未经审核公开。
- 只有真实证据、CI、安全回归及独立审查均满足后，才可创建最终候选 PR；仍需独立明确的合并授权，不能自动修改 main。
